# Одна QR-ссылка на «1С-Рарус: Мероприятие»

Статическая страница для GitHub Pages. QR ведёт на постоянный адрес страницы. Чтобы поменять магазин или заменить карточку приложения, обновите ссылки и повторно опубликуйте страницу по тому же адресу.

Настроены прямые ссылки из предоставленных сокращённых адресов. Для iOS используется App Store (витрина az), для Android — Google Play.

## Настройка

Откройте `docs/app/index.html`. Внутри блока `id="stores"` добавьте атрибут `href` с полным HTTPS-адресом карточки у каждой нужной строки. Если адрес содержит несколько параметров, запишите разделители как `&amp;`.

| ID строки | Ссылка |
| --- | --- |
| `app-store` | Приложение в App Store |
| `google-play` | Приложение в Google Play |
| `rustore` | Приложение в RuStore |

Для недоступного магазина оставьте строку без `href`. В `data-android-default` укажите `google-play` или `rustore`. Для смены видимого названия отредактируйте заголовки `h1` и `title`.

## Как работает переход

- На iPhone и iPad страница открывает App Store. Для iPad в режиме настольного сайта дополнительно проверяются платформа и поддержка нескольких касаний.
- На Android открывается выбранный магазин. Если его ссылка отсутствует, используется другой настроенный Android-магазин.
- На компьютерах, неизвестных устройствах и при отсутствии ссылки для текущей платформы посетитель видит доступные магазины. Эти ссылки работают и с выключенным JavaScript.
- Для ручного выбора на телефоне откройте страницу с параметром `?choose=1`. Автоматический переход использует признаки, которые передаёт браузер. Страница не проверяет наличие установленного магазина.

## Публикация

1. Поместите содержимое проекта в выделенный репозиторий и отправьте изменения в ветку публикации.
2. В GitHub откройте **Settings → Pages → Deploy from a branch**, выберите ветку и папку **/docs**, сохраните. [Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
3. Дождитесь успешной публикации. Откройте адрес из **Settings → Pages**. Стартовая страница ведёт в **app/**. Для сайта репозитория адрес включает имя репозитория. Сохраните полный адрес страницы приложения.
4. Проверьте этот адрес на телефонах и откройте вариант с `?choose=1`, чтобы проверить каждую карточку вручную.

Для локального просмотра из корня проекта выполните `python3 -m http.server 8000 --directory docs` и откройте `/app/` на локальном сервере.

## Выпуск QR

После публикации установите библиотеку Segno в виртуальное окружение. Она нужна только для выпуска файлов. Из корня проекта выполните:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install segno
.venv/bin/python make_qr.py 'ВСТАВЬТЕ_ОПУБЛИКОВАННЫЙ_АДРЕС_СТРАНИЦЫ_APP'
```

Скрипт проверяет наличие ссылок для обеих платформ и совпадение опубликованной страницы с локальной копией. Он записывает **app-qr.svg** для макетов и печати и **app-qr.png** для экрана. При размещении сохраните белую рамку вокруг кода. Смена адреса самой страницы потребует нового QR.
